# Investigation into starling murmurations

An investigation into the behaviour of starling murmurations (following the observation of one in Suffolk). We read some existing literature on the mathematics behind the phenomenon, and attempt to reproduce them via python simulations.

The notebooks has the following sections:
1. Background research, and a recount of some of the literature and ongoing research in the area.
2. First model: Basic flock dynamics
3. Adding collective turns
4. Second Model: Intertial-spin dynamics
5. An investigation into turning-wave propagation (remains to be implemented)
